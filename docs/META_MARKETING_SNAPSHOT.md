## 💡 학습한 메타 광고 핵심 (기억할 것)

### 작동 원리
- **메타 광고 = 관심사·행동 기반** (네이버 검색광고와 정반대 — 키워드 없음)
- **메타 = 학습 기계** (1-2주 데이터 쌓이면 자동으로 타겟 정밀화)
- **과금 방식: CPM 기본** (1,000회 노출당 5,000~15,000원)
- 일 예산만 설정 → 메타가 자동 최적화

### 한국 시장 특수성
- **한국 메타는 종교 관심사 타게팅 차단** (2022년 정책)
- 대안: 광역 타게팅 + 광고 소재로 자기선별

### 광고 발신자 (Identity)
- **Facebook 페이지는 광고의 중심축** — 페이지 없이 메타 광고 불가
- 인스타 계정 없어도 **"Facebook 페이지 사용"** 옵션으로 인스타 노출 가능
- 새 비즈니스 포트폴리오는 자동 검토 트리거 가능 (48시간 소요)

### 노출 위치
- **정적 이미지 가능**: 피드(페북/인스타), 스토리(페북/인스타), Marketplace, 탐색 홈
- **동영상 전용 (정적 이미지 불가)**: Audience Network 보상형 동영상, Facebook 인스트림 릴스
- 어드밴티지+ 노출 위치 = AI 자동. 수동 노출 위치 = 직접 선택. 정적 이미지는 수동 권장

### 광고 비율
- **1:1** (정사각형): 피드용
- **9:16** (세로): 스토리·릴스용 (풀스크린)
- **1.91:1** (가로): Marketplace 등 보조

### 캠페인 목표

  - CTR 정상, 가입 X → 랜딩 개선

## 🎓 오늘 학습한 헷갈리기 쉬운 용어

| 헷갈림 | 정정 |
|---|---|
| 구글 애드센스 vs 구글 애즈 | **광고하려면 "구글 애즈(Google Ads)"**. 애드센스는 사이트 운영자가 광고 띄워서 돈 받는 거 |
| 검색 테마 vs 키워드 | **"검색 테마"** = P-Max 캠페인의 AI 자동 운영 단어. 일반 검색 광고는 "키워드". P-Max는 1인 사업자에게 부적합 |
| Audience Network 보상형 동영상 | 정적 이미지 게재 불가. 노출 위치에서 빼야 함 |
