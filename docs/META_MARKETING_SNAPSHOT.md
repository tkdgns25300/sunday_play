→ 정적 이미지 광고는 **수동 노출 위치 + 동영상 슬롯 제외** 가 안전.

## 💡 학습한 메타 광고 규칙 (기억해둘 것)

- **한국 메타는 종교 관심사 타게팅 차단됨** (2022년 정책 변경)
    - 직접 "기독교"/"교회" 검색해도 안 나옴
    - 대안: 광역 타게팅 + 픽셀 학습 + 광고 소재로 자기선별
- **첫 광고는 "트래픽" 캠페인** — 픽셀 데이터 50건 이상 쌓여야 "전환" 캠페인 가능
- **CTA "더 알아보기"** — 트래픽 캠페인용 (클릭 ↑, 전환 ↓)
- **이미지는 미니멀하게** — AI 일러스트 티 강하면 신뢰도 ↓, 미니멀 디자인 권장
- **여러 문구 변형 등록** → 메타 자동 A/B 테스트로 최적 조합 선택
- **Facebook 페이지는 광고의 중심축** — 페이지 없이는 메타 광고 자체가 불가능
- **정적 이미지는 동영상 전용 슬롯에 못 들어감** — Audience Network 보상형 동영상, 릴스 인스트림 등 제외 필요
- **어드밴티지+ 노출 위치는 정적 이미지에 비효율** — 수동 노출 위치로 페북/인스타 피드·스토리 중심 선택 권장
- **비즈니스 포트폴리오는 페북 개인 계정과 별개** — 인스타 계정을 광고용으로 등록하려면 비즈니스 포트폴리오에 자산 추가 필요
- **메타 검수는 비즈니스 포트폴리오 단위로 제한 가능** — 새 포트폴리오는 자동 검토 트리거될 수 있음, 풀리는 데 48시간 소요
