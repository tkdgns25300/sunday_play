## ⏳ 집에서 이어서 할 일

### 1. Meta Pixel 정상 동작 검증 (필수, 5분)

**방법 A — Meta Pixel Helper (가장 정확)**
1. Chrome 에 [Meta Pixel Helper](https://chrome.google.com/webstore/detail/meta-pixel-helper/fdgfkebogiimcoedlicjlajpkdmockpc) 설치
2. `https://sundayplay.life` 접속
3. 확장 아이콘 클릭 → "Pixel found, 1 event" + `PageView` 이벤트 확인
4. 로그인 시도 → `CompleteRegistration` 이벤트 발사 확인
5. 게임 상세 페이지 진입 → `ViewContent` 확인

**방법 B — Meta 이벤트 매니저 테스트 이벤트 탭**
1. 비즈니스 → 이벤트 매니저 → 해당 데이터셋
2. **테스트 이벤트** 탭 → 본인 사이트 URL 입력
3. 사이트에서 활동 → 실시간 이벤트 표시 확인

### 2. Instagram 액세스 승인 (선택, 5분)
- 인스타 앱 → 프로필 → ☰ → 설정 → **비즈니스 도구 및 관리** 또는 **계정 센터** → 요청 수락
- 안 보이면 그냥 무시. 페이스북 피드만으로도 광고 가능.

### 3. 결제수단 등록 확인 (필수)
- 비즈니스 설정 → **청구 및 결제** → 카드 등록 확인
- 해외결제 가능한 신용/체크카드 필요

### 4. 첫 광고 캠페인 생성

#### 4-1. 캠페인 목표 선택
- **초기 1~2주: "트래픽" 캠페인** (픽셀 데이터 적은 상태에서 메타 최적화 잘 안 됨)
- 데이터 쌓이면 → **"판매(전환)" 캠페인** 으로 전환

#### 4-2. 추천 광고 세트 설정
```
위치:    대한민국
연령:    25~55세
성별:    전체
관심사:  기독교, 교회, 주일학교, 기독교 교육, 성경
언어:    한국어
일 예산:  10,000원 (시작)
```

#### 4-3. 광고 소재 (캐러셀 추천)
- 슬라이드 1: 게임 썸네일 + 후킹 카피 ("이번 주 주일학교 게임 고민?")
- 슬라이드 2: PPT 다운로드 강조 ("진행 자료까지 한 번에")
- 슬라이드 3: 가입 혜택 ("가입하면 1,000 크레딧 무료")
- CTA: "지금 시작하기" → `https://sundayplay.life`

#### 4-4. 광고 노출 위치
- 자동 게재 위치 (메타가 알아서 페북·인스타 분배) 권장
- 인스타 액세스 승인 안 됐으면 → 페이스북 피드만 자동 노출

### 5. (선택, 차후) 전환 API 서버 측 구현

## 📊 운영·평가 기준

### 첫 1주
- **노출량**: 메타가 광고 잘 배포하나? (일 1만원 기준 1,500~5,000 노출 예상)
- **CTR**: 1~3% 정도면 정상. 0.5% 미만이면 소재 교체
- **랜딩 페이지 도달**: 픽셀 PageView 데이터로 확인

### 2~4주
- **CompleteRegistration 이벤트 수**: 가입 전환
- **CAC**: 광고비 ÷ 가입자 수. 1만원 이하면 양호
- **첫 충전 전환**: Purchase 이벤트 수

### 시나리오 판단
| 결과              | 액션                                       |
| ----------------- | ------------------------------------------ |
| CTR 정상, 가입 X | 랜딩 페이지 가입 유도 개선                 |
| CTR 낮음          | 소재 교체 (이미지/카피)                    |
| 가입 정상, 충전 X | 가격 인식·웰컴 크레딧 안내 개선           |
| 전체 좋음         | 예산 2~3배 증액 + "전환" 캠페인으로 전환 |
