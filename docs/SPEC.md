# Sunday Play — 기획서

## 프로젝트 개요

- **프로젝트명:** Sunday Play
- **도메인:** sundayplay.life
- **한 줄 설명:** 교회 레크레이션 큐레이션 플랫폼
- **수익 모델:** 크레딧 기반 결제 (단건 게임 자료 구매)
- **타겟 사용자:** 주일학교 교사, 청년부 리더, 교역자 등 주일을 위해 게임을 준비해야 하는 크리스천들
- **타겟 시장:** 한국 (국내 우선 런칭)

---

## 핵심 기능

### 1. 게임/활동 목록 (데이터 모델 및 뷰)

사용자가 리스트에서 '직관적'으로 판단하고, 상세 페이지에서 '사역'에 바로 적용하게 만드는 구조.

- **카드 뷰 (Summary Card):** 한눈에 보는 정보
  - **콘텐츠:** 게임명, 썸네일, 핵심 태그(대상, 공간 등)
  - **메타데이터:** 소요 시간, 권장 인원, 난이도, 크레딧 가격
  - **상태 배지:** 구매 완료 시 리본 표시
- **상세 페이지:** 게임 클릭 시 풀 페이지로 이동 (SSG 정적 생성)
  - **기본 정보:** 준비물 리스트(외부 구매 링크 지원), 난이도(3단계), 상세 진행 스텝
  - **Sunday Play 특화:**
    - **말씀 연결:** 연관 성경 구절 + 아이들에게 전할 메시지 요약
    - **변형 팁:** 인원이 적거나 장소가 좁을 때의 대안
    - **유의사항(safetyNotes):** 안전 관리 포인트
  - **다운로드 섹션 (유료):** 진행 PPT(pptx) + 준비물 자료(pdf)

### 2. 필터 및 검색 (Search & Taxonomy)

교사가 처한 '상황'에 따라 가장 빠르게 검색 결과에 도달하게 설계. 필터/정렬/상세 토글 상태는 URL params로 유지되어 뒤로가기 시 복원됨.

- **기본 필터:** 대상(연령대), 인원수
- **상세 필터:** 장소, 준비 시간, 활동성, 난이도, 품성
- **대상(Age Group):** 유치부 / 유년부 / 초등부 / 중고등부 / 청년부 / 장년부
- **활동성(Energy Level):** 3단계 (정적 / 보통 / 활동적)
- **난이도(Difficulty):** 3단계 (쉬움 / 보통 / 어려움)
- **공간(Environment):** 실내 / 야외 / 온라인
- **준비 시간(Prep Time):** 바로 시작 / 간단한 준비 / 미리 준비 필요
- **품성(Character Qualities):** 49가지 품성 멀티 선택(검색 지원)
- **인원수 범위(GroupSize):** 5명 미만 / 5~10명 / 10~30명 / 30명 이상
- **정렬:** 추천순(기본) / 크레딧 가격 / 소요시간 / 난이도 (동일값 시 추천순 하위 정렬)

### 3. 수익화 — 크레딧 결제 모델

#### 무료 범위

- 전체 게임 목록 브라우징 및 필터/검색
- 게임 카드 정보 (제목, 썸네일, 태그, 요약, 메타데이터)
- 게임 상세 페이지 가이드 (진행 스텝, 준비물, 말씀 연결, 변형 팁)
- **웰컴 크레딧 1,000원** (신규 가입 시 자동 지급)

#### 유료 범위 (게임당 크레딧 차감)

- **진행 PPT(pptx) 다운로드** — 즉시 사용 가능한 슬라이드
- **준비물 자료 PDF** — 인쇄용 도안, 활동지 등
- **게임당 가격:** 500 / 1,000 / 1,500 / 2,000 크레딧 (게임별로 다름)

#### 크레딧 충전 패키지

| 결제 금액 | 지급 크레딧 | 보너스 |
|---|---|---|
| ₩3,000 | 3,000 | - |
| ₩5,000 | 5,250 | +5% |
| ₩10,000 | 11,000 | +10% |
| ₩50,000 | 60,000 | +20% |

- **결제 PG:** PortOne V2 (NHN KCP)
- **간편결제:** 카카오페이, 토스페이, 애플페이 (심사 진행 중)
- **크레딧 유효기간:** 약관상 3개월 (KCP 요구사항, 실제는 정책 따라 연장)

### 4. 사용자 기능

- **마이페이지(`/mypage`):** 크레딧 잔액, 충전 이력, 구매한 게임 목록
- **간편 공유:** 게임 상세 URL 복사
- **다크모드:** 시스템 설정 기반

### 5. 향후 기능 (Phase 3)

- **보관함:** 게임 저장/삭제
- **리뷰:** 별점 + 텍스트, 평점 기반 정렬
- **현장 모드(Presenter Mode):** 폰트 200% 확대 + 단계 넘기기 큰 버튼
- **진행 보조 툴킷:** 인앱 타이머, 랜덤 팀 나누기
- **AI 추천 엔진:** 공과 주제 입력 → 맞춤 게임 3종 추천, 위클리 큐레이션

## 기술 스택

- **Framework:** Next.js 16+ (App Router, SSG)
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS 4 + shadcn/ui
- **DB/Auth:** Supabase (PostgreSQL + Auth + RLS)
- **결제:** PortOne V2 + NHN KCP
- **배포:** Vercel (커스텀 도메인 sundayplay.life)
- **반응형:** 모바일 퍼스트 (교사들이 현장에서 폰으로 가이드 확인)
- **인증:** Google OAuth (Supabase Auth) — KCP 간편결제 심사용으로 이메일 로그인 임시 활성
