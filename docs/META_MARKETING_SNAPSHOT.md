## 🧪 게시 후 검증 단계

### Day 1 — 검수 확인
- 메타 검수 통과 (보통 1~12시간) → 광고 노출 시작
- 광고 거부 시: 사유 확인 → 이미지/문구 수정 → 재제출

### Day 1~3 — 노출 확인
- 예상: 일 1만원 기준 노출 1,500~5,000회
- CTR(클릭률): 정상 1~3% / 0.5% 미만이면 소재 교체
- 픽셀 이벤트: 이벤트 매니저에서 `PageView` 증가 확인

### Day 7 — 1차 평가
- 클릭 수, CPC, 가입 전환 측정
- 시나리오:
    - CTR 정상, 가입 X → 랜딩 페이지 개선
    - CTR 낮음 → 소재(이미지/카피) 교체
    - 가입 OK, 충전 X → 가격·웰컴 크레딧 안내 개선
    - 전체 좋음 → 예산 2~3배 증액 검토

### Day 14~30 — 전환 캠페인 전환
- 픽셀에 가입 이벤트 50건+ 쌓이면 → "판매(전환)" 캠페인으로 변경
- 또는 유사 타겟(Lookalike) 생성

## 📊 운영·평가 기준

### 첫 1주
- **노출량**: 메타가 광고 잘 배포하나? (일 1만원 기준 1,500~5,000 노출 예상)
- **CTR**: 1~3% 정도면 정상. 0.5% 미만이면 소재 교체
- **랜딩 페이지 도달**: 픽셀 PageView 데이터로 확인

### 2~4주
- **CompleteRegistration 이벤트 수**: 가입 전환
- **CAC**: 광고비 ÷ 가입자 수. 1만원 이하면 양호
- **첫 충전 전환**: Purchase 이벤트 수

### 시나리오 판단표
| 결과              | 액션                                       |
| ----------------- | ------------------------------------------ |
| CTR 정상, 가입 X | 랜딩 페이지 가입 유도 개선                 |
| CTR 낮음          | 소재 교체 (이미지/카피)                    |
| 가입 정상, 충전 X | 가격 인식·웰컴 크레딧 안내 개선           |
| 전체 좋음         | 예산 2~3배 증액 + "전환" 캠페인으로 전환 |

## 💡 학습한 메타 광고 규칙

- **한국 메타는 종교 관심사 타게팅 차단됨** (2022년 정책 변경)
    - 직접 "기독교"/"교회" 검색해도 안 나옴
    - 대안: 광역 타게팅 + 픽셀 학습에 의존 + 광고 소재로 자기선별 유도
- **픽셀 학습은 타게팅 대체가 아니라 위에서 정밀화**
    - 본인 타겟 풀 안에서 메타가 전환 가능성 높은 사람 우선 노출
    - 최소 주 50건 전환 이벤트가 쌓여야 효과적
- **첫 광고는 "트래픽" 캠페인** — 픽셀 데이터 적은 상태에서 "전환"은 학습 불가
- **CTA "더 알아보기"** — 트래픽 캠페인용 (클릭 ↑, 전환 ↓)
- **이미지에 "20% 미만 텍스트"** — 메타 가이드 (강제 아님, 권고)
- **여러 문구 변형 등록** → 메타 자동 A/B 테스트로 최적 조합 선택
